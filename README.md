# New Collection | Raw Style

A static e-commerce landing page built using pure HTML5 and CSS3, styled specifically for a modern fashion collection showcasing Y2K and Grunge aesthetics.

## Features
* **Hero Header:** Includes navigation links, title layout, action buttons, and a cover background image.
* **Product Showcase Cards:** Top cards layout featuring bold titles, descriptive tags, and rounded product images.
* **Alternating Feature Layouts:** Detailed fashion showcases using `display: flex` and `flex-direction: row-reverse` for visual balance.
* **Semantic Structure:** Clean HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`).
* **Custom Styling:** Styled buttons, custom typography using Cambria serif fonts, and a dark theme (`background-color: black`).

## Tech Stack
* **HTML5**
* **CSS3** (Flexbox, Custom Button Styling, CSS Reset)
